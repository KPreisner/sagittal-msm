- **Per proof** excludes one-time precompute, which is reused across proofs that share a proving key.
- Values are from the closed-form model; sizes marked * were also measured, and measured counts match the model within 2%.
- **Storage** is points kept per input point (Sagittal tables, Yrrid's shifted copies).
- Sagittal is flat in n: it does b(1 - 2^-g)/g lookups per point whatever n is, and has no bucket reduction to amortize. Pippenger's best window c grows with n, so its cost per point falls. Sagittal's equivalent, g, grows only with table memory ((2^g - 1)/g points per input point).
