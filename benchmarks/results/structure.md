Structure of each algorithm at n = 2^20 on bls12-377, from the closed-form model. Generated by `benchmarks/structure.py`.

- **Buckets** are the accumulators held during one MSM. On a GPU each is a unit of parallel work that needs its own storage and synchronization.
- **Points per bucket**: mean, and the expected maximum (median). Sagittal's loads are fixed by n and g before seeing any scalars: each bucket gets one table lookup per batch. Pippenger's depend on the scalars (Poisson spread), and with textbook signed digits the top window can send a large share of all points to one bucket. Real GPU codes mitigate this: Yrrid sorts buckets by size and negates scalars with the top bit set, which this model does not include.
- **After accumulation** is EC operations that start only once every bucket is final: Pippenger's bucket reduction and window combine, Sagittal's combine.
- **Field mults** are per point, XYZZ (mul + sqr). **Device memory** is points, scalars and precomputed data (96-byte points).
